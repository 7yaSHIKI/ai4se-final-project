# 冷启动验证操作指南

## 目标
验证 SPEC.md 和 PLAN.md 是否足够清晰，让陌生的 AI agent（无历史上下文）能独立完成任务。

---

## 第 1 步：打开网页版 Claude

访问：https://claude.ai

使用一个**全新的对话**（不要在当前项目的对话中进行）。

---

## 第 2 步：上传文件

在新对话中，上传以下 2 个文件：
1. `SPEC.md`
2. `PLAN.md`

---

## 第 3 步：发送验证提示词

复制以下提示词发送给 Claude：

```
你是一个 Python 开发者。请严格按照 PLAN.md 中的 Task A1 要求，创建项目目录结构。

要求：
1. 仅根据 SPEC.md 和 PLAN.md 中的信息完成任务
2. 如果信息不足或有歧义，明确指出缺少什么
3. 输出你创建的完整命令或代码

开始实现 Task A1。
```

---

## 第 4 步：观察并记录

**记录以下内容**：

### ✅ 成功指标
- [ ] AI 能理解任务目标
- [ ] AI 能找到所需的技术栈信息
- [ ] AI 能独立完成实现
- [ ] 生成的代码/命令符合 PLAN 要求

### ❌ 失败指标（需要记录）
- [ ] AI 提问了什么？（说明 SPEC/PLAN 信息不足）
- [ ] AI 做出了什么假设？（说明规格有歧义）
- [ ] AI 偏离了 PLAN 的设计吗？（说明 PLAN 不够明确）
- [ ] AI 无法完成任务的原因是什么？

---

## 第 5 步：进行第二次验证（可选但推荐）

在**同一个对话**中，继续发送：

```
现在请实现 Task C1：订阅管理服务 - 添加订阅。

要求同上：
1. 仅根据 SPEC.md 和 PLAN.md 完成
2. 如果信息不足，明确指出
3. 输出完整的实现代码

开始实现 Task C1。
```

记录同样的成功/失败指标。

---
